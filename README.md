# Rogue Game

**Пиксельный Rogue-Like c пошаговым геймплеем.** Игра задумана как линейный рогалик. В играбельном прототипе копейщик с мечом выходит на арену с пятью сердцами. Чтобы победить, нужно отбиться от всех волн слизней на пути у игрока.

[Запуск](#запуск) · [Управление](#управление) · [Механики прототипа](#механики-прототипа) · [Линейный забег](#линейный-забег)

## Запуск

Установи Python 3.13 и открой PowerShell в папке проекта, где находятся `main.py` и `Arts/`.

```powershell
py -m pip install pygame
py main.py
```

## Управление

| Клавиша | Действие |
| --- | --- |
| `Стрелочки вверх вниз` | Выбор между врагами |
| `Пробел` | Удар в направлении последнего движения |

## Механики прототипа

- **Ближний бой.** Враги преследуют пехотинца. Один точный удар любым мечом убирает врага. Между взмахами есть короткая пауза.
- **Пять сердец.** Удар отнимает определённое количество хп, в зависимости от типа врага.
- **Новая расстановка.** Состав группы разный и в каждом последующем уровне усложняется.
- **Конец попытки.** Победа наступает после прохождения всех уровней. Если сердца заканчиваются, забег завершается поражением.

## Линейный забег

Между комнатами копейщик сохраняет оставшиеся сердца и полученное снаряжение. После гибели новая попытка начинается с первой комнаты.
